# OUN（非公式の岡山大学学生アプリ）の配布ファイル

OUN は、岡山大学の学生のための**非公式**のアプリです。時間割・Moodle・課題・バス・キャンパスの地図・AI など、大学生活に使う画面を 1 つにまとめています。
**岡山大学の公式のアプリ・サービスではありません。** 個人が開発・運営しています。

- 案内（機能・使い方・お知らせ）: https://jinrui0713.github.io/okadai-app/
- English: https://jinrui0713.github.io/okadai-app/en/

### Windows・Android（ベータ版）

**最新の版は、[Releases](../../releases/latest) の「Latest」です**（現在: [v0.2.4](../../releases/tag/v0.2.4)）。ベータ版（不具合があるかもしれません）です。

| ファイル | 内容 |
| --- | --- |
| `OUN-<版>.msi` | **Windows 用のインストーラ**。Intel・AMD の PC も ARM の PC も、このファイル 1 つ。管理者の確認なし |
| `OUN-<版>-windows-x64.zip` / `OUN-<版>-windows-arm64.zip` | インストールなしで使う版（展開して `OUN.exe` を起動） |
| `OUN-<版>-windows-*-update.zip` | 自動更新が使う、軽い更新用（手動では使いません） |
| `OUN-<版>-beta-android.apk` | **Android 用**（「提供元不明のアプリ」の許可が必要） |

- ベータ版のため、不具合があるかもしれません。
- ストアの署名がないため、Windows は初回に SmartScreen が警告することがあります。「詳細情報」→「実行」で起動できます。
- Windows 版は、新しい版を自動で見つけて、軽い更新用の zip で置き換えます。
- ファイルの SHA256 は、各 Release の説明にあります。

# OUN — an unofficial student app for Okayama University

OUN brings the timetable, Moodle, assignments, buses, the campus map and an on-device AI into one app. It is **not** an official app or service of Okayama University; it is developed and run by an individual.

- Site (features, guide, news): https://jinrui0713.github.io/okadai-app/en/
- iPhone, iPad, Mac, Apple Watch: [App Store](https://apps.apple.com/app/id6823992697) (free)
- **Windows 10/11 and Android 8+ (beta)**: download from [Releases](../../releases). Use the **latest release**, currently [v0.2.4](../../releases/tag/v0.2.4). Windows may show a SmartScreen warning on first launch ("More info" → "Run anyway"); the Windows app updates itself.
- [Privacy policy (English summary)](https://jinrui0713.github.io/okadai-app/en/privacy/) · Contact: okadaiapp@gmail.com
